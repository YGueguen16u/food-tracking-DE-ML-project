\section{Parquet Conversion System}

\subsection{Overview}
The Parquet conversion system (transform\_6\_parquet.py) provides a robust solution for converting Excel files to the columnar Parquet format. This conversion optimizes storage and query performance while preserving the original data structure and types.

    def convert_file(self, excel_path, parquet_path):

        Convert Excel file to Parquet format

        - Converts numeric columns

        """
        for sheet_name in sheet_names:

            df = pd.read_excel(temp_excel, sheet_name=sheet_name)
            
            # Convert numeric columns
            numeric_columns = ["total_calories", "total_lipids", ...]
            for col in numeric_columns:
                df[col] = pd.to_numeric(df[col], errors='coerce')
                
            # Save as Parquet
